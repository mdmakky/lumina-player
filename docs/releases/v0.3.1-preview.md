**Lumina Player 0.3.1-preview**: a fast, modern media player (Qt 6 + libmpv) built around smooth seeking.

> **Preview release, not 1.0.** It is developed and tested on Fedora and macOS. Expect rough edges and please report them.

## Download

Pick **one** file. RPM and DEB are built per distro release, so use the one that matches yours (`rpm -E %fedora`, `lsb_release -rs`).

| You use | File | Install |
|---|---|---|
| Any Linux with Flatpak | `Lumina-Player-v0.3.1-preview.flatpak` | `flatpak install --user ./Lumina-Player-*.flatpak` |
| Fedora 43, 44, 45 | `lumina-player-0.3.1-1.fc<N>.x86_64.rpm` | `sudo dnf install ./lumina-player-*.rpm` |
| Ubuntu 24.04, 25.10, 26.04 | `lumina-player_0.3.1-1_ubuntu<N>_amd64.deb` | `sudo apt install ./lumina-player_*.deb` |
| macOS (Apple Silicon) | DMG: **not attached yet**, it will be added here once rebuilt from this tag on a Mac | open, drag to Applications, right-click, Open |

Full instructions, codecs and troubleshooting: [docs/INSTALL.md](https://github.com/mdmakky/lumina-player/blob/main/docs/INSTALL.md).
Verify downloads with `SHA256SUMS.txt`: `sha256sum -c SHA256SUMS.txt --ignore-missing`.
**Windows is not part of this release.** Until the macOS DMG is attached, Mac users can build from source ([docs/BUILDING.md](https://github.com/mdmakky/lumina-player/blob/main/docs/BUILDING.md)).

## What has been verified

- **Every RPM and DEB** is installed in a clean container of its own release, and then the app starts, loads a video, seeks, pauses and resumes (virtual display, software rendering, no audio).
- **On real hardware:** Fedora 45 (GNOME, Wayland, AMD GPU) with the RPM and the Flatpak, including sound and VAAPI hardware decoding; macOS on Apple Silicon (with an earlier build than this tag).
- **Not verified:** the DEB on a real Ubuntu desktop, other distributions, NVIDIA hardware decoding, Windows.

## Highlights

- Floating-overlay player, playlist, chapters, A-B loop, bookmarks, 10-band equalizer, per-file settings
- Start screen and library: video and music, search, tags, thumbnails, duplicate detection, playlists, favorites
- Network streams (HTTP, RTSP, RTMP, page URLs through yt-dlp), seek-bar hover thumbnails
- Subtitle styling (including Bengali fonts), picture presets, track menus
- Bengali and English UI, Dark / Light / OLED themes, rebindable shortcuts and mouse actions
- Linux: MPRIS media controls, screensaver inhibit, volume follows the system volume
- No account, no telemetry. An update check exists but is off by default and downloads nothing

Full list: [CHANGELOG.md](https://github.com/mdmakky/lumina-player/blob/main/CHANGELOG.md).

## Known limitations

- **The RPM is not GPG-signed.** `dnf` installs it from a terminal; GNOME Software asks for an administrator password and warns "Potentially unsafe".
- **Fedora codecs:** Fedora's FFmpeg cannot decode E-AC3, DTS or software H.264. Enable RPM Fusion and install `libavcodec-freeworld` (see the install guide). The Flatpak needs nothing.
- **macOS** is ad-hoc signed and not notarized: Gatekeeper asks you to confirm the first launch.
- Ubuntu 22.04 and Debian 12 are not supported (Qt older than 6.4). Use the Flatpak.
- Not included yet: Developer ID signing, automatic update install, OpenSubtitles download, Windows build.
